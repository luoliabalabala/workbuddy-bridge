# 2.1.0 修复与验证

桥在发送前保存任务指纹、会话基线和持久化票据。后续使用原票据恢复，使用原重试键去重。转录包装、预建会话和延迟落盘都通过本回合证据核对。导航以稳定的会话标识验证，取消时还会检查是否已经出现后续用户回合。

从本版起，应用在运行但未开放调试端口时，默认强制重启。端口正常时直接复用。用配置项 autoRestart 关闭这一行为，或用 launch:false 只读查询。文件复制要求预先指定允许的源目录。

28 项离线测试通过。WorkBuddy 5.11.3 上验证了真实会话导航、续聊、票据恢复与停止控件。停止控件请求后观察到非忙，未独立验证后端取消原因与模型计费信息。
